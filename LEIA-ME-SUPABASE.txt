CONFIGURAR SUPABASE NO SITE EUODEENE

1. No Supabase, crie um projeto.
2. Vá em SQL Editor e rode o arquivo supabase.sql.
   IMPORTANTE: antes de rodar, troque COLE_AQUI_SEU_EMAIL_DO_SUPABASE pelo seu email de admin.
3. Vá em Authentication > Users > Add user.
   Crie um usuário com o mesmo email usado no SQL e uma senha.
4. Vá em Project Settings > API.
   Copie Project URL e anon public key.
5. Abra script.js e troque:
   SUPABASE_URL
   SUPABASE_ANON_KEY
   ADMIN_EMAIL
6. No index.html confira que existe esta linha antes do script.js:
   <script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
7. Suba no GitHub:
   git add .
   git commit -m "conectando supabase"
   git push

NUNCA coloque a service_role key no site. Use só a anon public key.
